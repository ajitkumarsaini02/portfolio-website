# Ajit Kumar Saini — Developer Portfolio (React + Vite)

A modern, high-performance developer portfolio built with **React.js**, **Vite**, and **Vanilla CSS**. Features dynamic canvas particles, glassmorphism aesthetics, interactive coding milestones, theme toggle (Dark/Light), and a project showcase highlighting full-stack MERN engineering.

---

## 🚀 Features

- **Built with React & Vite**: Fast HMR, clean modular components, and optimized production bundle.
- **Full-Stack MERN Showcase**: Highlights **CodeTrack** (DSA tracking across 5 platforms with JWT auth & parallel sync scrapers) and **TaskMaster**.
- **Interactive Cyber Particles**: Lightweight HTML5 Canvas particle background adhering to theme colors.
- **Dynamic Typing Effect**: Seamlessly cycles through technical roles and specializations.
- **Interactive Terminal Preview**: Real-time simulated developer object with 1-click clipboard copy.
- **Comprehensive Skills Matrix**: Categorized into Frontend (React.js), Backend & Database (Node.js, Express, MongoDB), Core CS (DSA, OOP, OS, CN), and Languages/Tools.
- **Coding Profiles & Milestones**: Detailed visual breakdown for LeetCode (500+ solved, rating 1527), CodeChef (2★, rating 1408), GitHub, and GFG.
- **Interactive Project Filtering**: Instant filtering across Full-Stack MERN and Frontend/Web applications.
- **Contact Form with Celebration**: Built-in validation and particle confetti animation upon sending.
- **Dark & Light Mode**: Persistent theme state saved in `localStorage`.

---

## 🛠️ Tech Stack

- **Frontend**: React.js 18, Vite 6
- **Styling**: Vanilla CSS (Custom Design System, Glassmorphism, CSS Variables)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti, HTML5 Canvas Particle Engine

---

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

3. **Build for production**:
   ```bash
   npm run build
   ```
   The production build will be generated in the `dist/` directory.

4. **Preview production build**:
   ```bash
   npm run preview
   ```
